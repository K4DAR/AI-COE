##  Quick Start

```bash
# 1. Setup (first time only)
pip install -r requirements.txt
echo "OPENAI_API_KEY=sk-your-key" > .env

# 2. Run
streamlit run app.py

# 3. Open
http://localhost:8501

# 4. Click "Initialize Bot" and start asking questions!
```
